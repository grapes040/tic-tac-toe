# Tic Tac Toe

A browser-based Tic Tac Toe game where you play against the computer. Built as a practice project while learning web development.

## How to play

1. Choose **X** or **O**. X always goes first.
2. Click an empty square to place your mark.
3. The computer replies with its own move.
4. Get three in a row (across, down or diagonally) to win.
5. A popup shows whether you won, lost or tied. Press **Restart** to play again.

## Features

- Player vs computer (the computer picks a random empty square)
- Win, lose and tie detection
- The computer moves first if you pick O
- Result popup with a restart button
- Responsive layout that works on phones and desktops

## Built with

- HTML
- CSS
- JavaScript (no libraries)
